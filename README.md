# Proyecto 1: API de abandono bancario

Repositorio del proyecto FastAPI:

- Código: [`api_abandono_banca/`](api_abandono_banca)
- Interfaz y API: FastAPI
- Modelo: KNeighborsClassifier
- Artefactos: `artifacts/`

## Despliegue en Render

Usa este repositorio con `render.yaml` situado en la raíz. El Blueprint configurará `api_abandono_banca` como directorio raíz del servicio.
